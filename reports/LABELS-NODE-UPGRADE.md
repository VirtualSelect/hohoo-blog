# 中文界面与 Node.js 升级验收

## 修改

- 首页、文章、学习、项目与实验、近况、关于、资讯、周报、搜索和阅读上下文的栏目／状态／时间单位等普通英文标签接入 Docusaurus 原生翻译目录。
- 简繁中文显示本地化文案，英文页面保留英文。编号、内容 ID、分类存储值和路由不变；产品名、技术名与外部原文保留。
- 补充手机菜单、外链及系统主题模式的辅助技术翻译。
- 新增共享 `uiLabel` 标签映射，无 DOM 文本替换、无新增依赖、无自动翻译抓取正文。
- 本机 Node.js 22.4.0 → 26.8.2，npm/npx 10.8.1 → 12.0.2。新版并行安装，保留旧版；系统 PATH 已更新。新终端按系统 PATH 确认三个命令均来自新版安装目录。
- `.node-version`、packageManager、lock 根引擎元信息与两条 CI 工作流同步。运行环境文档明确排除在公开 Docs 内容索引之外。

## 验证

- 新 Node 下现有 42 项测试全部通过。
- 翻译版本检查通过；最终三语言生产构建通过。
- 实际浏览器检查简繁中文与英文首页；简体主要 8 个页面的 375px 布局无横向溢出。
- 繁体首页 1440、1280、1024、768、430、375px 全部无横向溢出。
- 手机菜单打开／关闭、深色模式及资讯无匹配结果可用；检查期间无浏览器控制台错误。
- `git diff --check` 通过，仅有仓库既有的换行转换提示。

## 局限

外部资讯暂无译文时仍显示来源语言，不恢复自动翻译。Node 26 为 Current 正式版，非 LTS；存在实验性 localStorage 提示，见 `docs/NODE-RUNTIME.md`。更新通知缓存权限提示不影响构建。尚未提交、推送或部署，线上运行时设置未变更。重新启动终端／IDE 后才能继承新的系统 PATH。
