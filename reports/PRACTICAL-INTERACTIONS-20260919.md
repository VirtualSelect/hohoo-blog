# 实用互动与折叠入口

## 功能与入口

- Java 首篇教程：错误诊疗室覆盖 401、429、读取超时和 JSON 解析失败，含逐步排查、Java 8 教学片段和官方/MDN 参考链接。实践伴侣是读者自己的四项自检。文章更新轨迹只显示 Git 已核实的 `35a395153c3645cdc1f9e1e4e4e82e0961e213af` 首次发布，不制造后续修订。
- AI 应用专题：流式输出观察窗支持普通文字与分段 JSON、取消、断线、重放，对比渐进展示和完整接收后展示。无网络调用、真实流速、Token 或费用推断。
- 虚拟实验室：三个固定预测题复用 stepRobot 执行规则，包含碰壁、转向、移动；展示地图和解答理由，无排行榜或作者实验成果。
- `/reading`：学习背包展示已有最近学习与私人便签，下方原收藏列表保留。支持 JSON 下载/复制、文件/文本导入、预览、默认保留冲突、明确选择覆盖，写入失败回滚。
- Radar：三个真实 signalId 的显式阅读问题与真实知识入口。只提示如何查找证据，不判断论文效果。
- 既有互动收进 TryIt，原生 details 默认折叠，锚点链接自动展开，文章正文不依赖它才能阅读。

## 数据与依赖

无新增依赖、路由、账号、模型调用或第三方数据上传。新本地实践 schema 与背包格式见 CONTENT-MODEL。无关锁文件保留。新增两份内容关系注册表，不修改来源文章或 Radar 状态。

核心新增组件：TryIt、ErrorClinic、StreamWindow、RobotPrediction、LearningBackpack、PracticeCompanion、ArticleHistory、RadarPractice。
复用：网格规则及样式、主题变量、语言上下文、现有收藏/学习数据、阅读清单、文章外壳。
