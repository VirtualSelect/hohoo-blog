# 博客体验走读与增量优化

## 当前结构

Next.js App Router 位于 `apps/web`，Markdown / JSON 内容和三语索引在构建时生成。页面沿用共享内容组件、阅读本地状态和 Radar 来源规则。分支 `codex/blog-experience-polish-20260916` 基于 `origin/main` 的 `3e3d507`。

## 走读发现

- 首页有真实教程、随笔、两个项目及资讯入口；教程类型标识却硬编码为 AI 应用开发，项目封面依赖数组顺序。
- 搜索有关键词和类型筛选，但空查询只展示空白，缺少起始导航。
- Radar 有关键词和方向筛选，但无法分享筛选链接，缺少来源筛选与结果数；发布时间与收录时间的关系不够明确。
- Docs 有桌面目录，但 1100px 以下隐藏；复制代码的反馈不复位；随笔侧栏仍展示学习方向。
- Learning 的收藏、随机探索、难度和本地学习进度已经存在，继续保留；Notes 等内容不足应由真实写作补齐，不能生成假成果。
- 当前设计文档仍有已过时的 Docusaurus 外壳描述，需要同步运行架构。

## 本轮修改

1. Radar 增加 URL 筛选、来源选择、清除条件、结果统计和真实收录时间说明，保持时间轴及空状态稳定。
2. 搜索提供已发布内容与常用入口，保持 Ctrl/⌘ K、Esc、原生 dialog 和类型查询。
3. Docs 提供移动目录、当前章节指示、复制反馈复位；随笔使用适合原创文章的导航。
4. 首页正确使用内容元数据，补充从真实教程到配套 Demo 的阅读指引，不新增规划页面。
5. 使用现有绿色设计变量、细分割线、可换行布局和三语文案，无新增依赖。
6. 专题页去掉重复文章列表，折叠后续选题，将真实内容和来源入口前置；项目章节使用既有翻译，统一 RAG / 周报类型标签。

## 风险与验证

重点防止 URL 同步破坏 Next.js 历史状态、SSR 访问浏览器对象、复制按钮重复注入、移动目录挤压正文。执行已有测试、内容/i18n 检查、构建及路由检查；浏览器验证六种宽度、深浅主题、搜索/筛选/目录与导航。最终结果补充于文末。

## 验收结果

- 分支：`codex/blog-experience-polish-20260916`。原有文章、来源配置和正式资讯数据未改动；新路由、内容 schema、依赖均为 None。
- `node --test tests/*.test.*`：48 项通过，覆盖内容关系、学习/阅读状态迁移、RSS、相关性与额度、来源与核验边界。
- `npm run test:web`：9 项通过，含三语内容索引及新增 URL 筛选/查询测试。
- `npm run news:check`：30 条现有资讯校验通过。
- `npm run i18n:check`：通过（这是翻译文件一致性的提示性检查，不是全站语言完整性证明）。
- `npm run build`：生产构建成功，完成 142 个生成任务；未增加依赖或构建警告。
- `npm run test:routes --prefix apps/web`：123 个页面检查无错误，脚本同时检查旧路由 308、RSS 等输出。
- 本轮 Next.js 修改文件的 Prettier 检查通过；全目录 `format:check` 仍报告 22 个未修改文件的既有格式问题，未混入全仓重排。
- 浏览器检查：Home / Radar / Docs 的 1440、1280、1024、768、430、375 宽度无横向溢出；目录在 1100px 以下使用可展开版本。代码与表格保留内部滚动。
- 深浅色：首页、资讯筛选、文章目录和搜索使用现有主题变量，桌面与手机均检查。三语新增入口/筛选文案正常；未将来源原文当作已翻译内容。
- 键盘：Ctrl+K 打开且聚焦输入框；Esc 关闭后焦点归还搜索按钮。目录锚点会定位正文并更新当前章节。复制成功后反馈复位。加载更多后焦点进入第一条新增资讯。
- 资讯筛选：组合筛选、无结果、清除、刷新恢复、跨页后退恢复均检查；第 30 条资讯的链接会展开到对应条目，而非停在前 12 条。
- 生产预览浏览器控制台无 error / warn。开发时编辑共享导出触发 Fast Refresh 整页刷新提示，未把开发提示当成生产错误。
- SEO：保留 canonical、语言路由、原文链接和 sitemap；核心正文仍由服务端提供。筛选参数不创建独立内容页面。
- 性能：无额外依赖、远端接口、抓取或模型调用；目录使用被动滚动事件与 requestAnimationFrame，卸载时清理。未宣称经过 LCP / CLS 专项基准测试。

## 尚需真实内容与后续建议

1. 优先共创第二篇“结构化输出”：用真实请求记录说明合法 JSON、字段校验和失败处理，关联现有 Java 实践集。
2. 完成一次既有检索对照实验，将方法、观察与结论分开记录，再发布 Lab；提案暂不算实验成果。
3. Notes 从文章中已经实际解释过的概念开始，由作者审阅后发布；LLM 与具身方向目前仍缺原创系列。
4. 历史共享页面还有少量繁简混用与旧式状态文案，可独立进行文案审校。已有源码格式欠账也宜单独处理。
5. RSS 自动筛选仍是规则筛选，不等于论文质量或事实核验；后续可基于实际误收样本迭代门槛。本轮未改变采集和发布规则。

上述后续工作未自动启动；本轮只改已有体验与真实内容的展示关系。
