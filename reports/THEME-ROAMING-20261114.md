# 主题漫游实现与验证

验收日期：2026-11-14。基于已发布的 `1907a7c` 完成主题漫游实现。2026-11-15 按用户要求纳入主干合并与发布；下列记录描述发布前的本地验收，线上结果以对应提交的部署状态为准。

## 实现

- 八张真实首页快照组成横向窗口，支持鼠标拖动、触摸滑动、前后按钮与键盘定位；打开面板才加载图片，不运行额外iframe或3D。
- 随机漫游优先未访问主题且排除当前；上一站在面板中保留，切换提示提供直接返回和关闭操作。
- 每日风景默认关闭。开启当天保持当前主题，按访客本地日期在新文档首次打开时推进；同日刷新保持一致。手动选择、随机、返回和固定当前主题会关闭每日模式。
- 使用 `huhohoo.roaming.v1` 记录有效主题ID、上一站及当日选择。沿用现有主题键，旧偏好、损坏记录和拒绝存储都有回退。跨标签存储事件合并后处理，日更不会影响已有阅读文档；站内导航重新挂载页头时保留其临时选择。
- 八种独立340ms装饰过渡立即应用新主题，避免阻塞内容。减少动态、后台直接切换；动画层不截获点击和焦点，结束、连切、导航与卸载均清理。

## 验证结果

- `npm run format:check`、`npm run typecheck`、`npm run test:web` 与 `npm run build` 通过；网站测试291项，生产构建622个页面。
- 状态与首屏相关26项测试覆盖旧默认、旧ID迁移、随机遍历、跨日稳定、部分写入失败、显式选择优先，并实际经过Webpack开发和生产模式打包后执行首屏脚本。
- 生产模式浏览器检查：八主题 × 1440/1280/1024/768/430/375，共48组布局；无页面横向溢出、面板溢出或越界控件，Esc后焦点回到入口，关闭面板不加载预览图。
- 完整随机序列覆盖全部八主题，返回、当日重载、固定主题、End/Enter键盘选择、查询参数与URL保持均通过。
- 模拟北京时间跨日：新标签轮换为新主题，旧阅读标签保持原主题且站内导航不改变；随后手动选题可跨标签同步。
- 真实鼠标拖动与移动端触摸滑动均只移动窗口，不误选主题。八种过渡均出现并移除，无残留交互遮挡。文章切换后保留原阅读段落；不同导航布局的视口偏移约98px。
- 禁用localStorage后仍可切换、显示保存失败说明，站内导航保留本次选择。
- 375px英文、繁体面板和八主题返回提示通过，控件保持44px高度。生产检查未发现页面异常或控制台错误。

## 资源与边界

无新增依赖。八张预览合计183,389 bytes，仅面板打开后请求；它们是中文首页的真实静态快照，首页布局改动后应重新拍摄。菜单文案支持三种语言。

每日风景按当前浏览器本地日期工作，无账号同步和后台调度；连续阅读不因午夜到来自动改变。数据拒绝保存时只在当前文档及其站内导航中保留临时选择，刷新恢复可读取的偏好。

生产构建客户端资源合计2,918,933 bytes，静态输出估算158,322,259 bytes，均通过既有预算。详细浏览器记录和截图保存在本轮外部验证目录 `theme-roaming-20261114/production`。
