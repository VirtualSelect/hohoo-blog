# 博客整体视觉协调验收

日期：2026-09-12。范围为 Docusaurus 博客，预览端口 4173；独立 Next.js GPU 实验（4180）保留。

## 调整

- 首页结构复修为居中纵向：简短介绍 → 完整 Hohoo 粒子 → 阅读／项目入口，移除左右双栏和重复个人名片；桌面与手机保持同一信息顺序。
- 配色复修：统一深靛蓝／暖米色底色、琥珀色强调、浅蓝／墨蓝文字及细边框；首页标题与主按钮使用琥珀色，头像恢复原色。首页外框与栏目页一致。
- 移除全站粒子背景和背景渐变，阅读页保持静态底色；暂停控件只在包含粒子字形的首页出现。
- 粒子展示改为透明画布，无独立卡片边框；浅色使用墨蓝／琥珀粒子，深色保留蓝白星光。主题切换即时重绘，周围星点向边缘淡出，交互与键盘控件保持可用。
- 复用已有组件和数据；没有新增依赖、改变内容或调整路由。

## 验证

- `npm run build`：中英文生产构建通过。
- `scripts/verify-editorial-visual.cjs`：首页、学习、项目、Radar、博客、LLM 文档、英文首页，共 7 个页面 × 2 个主题 × 6 种宽度（1440/1280/1024/768/430/375）无横向溢出。
- 移动菜单打开和 Escape 关闭通过；阅读页无背景 Canvas、无粒子暂停浮层；未发现页面 JS 异常。
- `scripts/verify-particle-wordmark.cjs`：采样、悬停划散、恢复、拖拽、复位、键盘、暂停、reduced-motion、中英文、浅色和 SSR 回退通过。
- 已检查桌面深浅色首页、文档页和手机整页截图；截图位于系统临时目录 `hohoo-editorial`。

浏览器使用已有 Playwright 运行时和 Headless Edge。手机为视口模拟，没有声称实体手机测试。此次调整尚未提交或部署。

页尾复修：结束语居中、页脚同底色、紧凑导航与版权层级。浏览器验收增加深浅主题页脚截图及背景一致性检查。
