# 正文检索盲审 · 主持人手册

当前为初判待收回，留出题也尚待人工审核和运行。本包供主持人使用。**只把 [participant.md](participant.md) 的独立副本交给判读者**，保留本页、脚本及留出题在主持人一侧。读过[逐题分析](../SECTION-SEARCH-V2-REVIEW.md)或已知 v2 标签的人，可参与公开复核；盲审请另选一位尚未看过这些材料的人。

## 发题和揭盲

1. 从仓库根目录运行检查命令。题面有 12 题，每题 3 段，包含逐题清单中的 9 题及 3 道已命中对照。题序和段落顺序都已打乱。题面只保留原题和连续原文，每段单独判断。同题的三段文字均不同。若两篇文章刊载同一段落，判读一次，揭盲时可查看各来源及排名。原文可能呈现与实验本身有关的术语、数字和局限。
2. 判读者在副本的 36 行中逐一填写判定和引文或理由。主持人先保留收到的原始文件，再运行揭盲命令。命令将初判文件指纹、候选对应的冻结段落链接、原排名与原标签输出到终端。两端换行按 LF 统一计算。机器只检查填答结构、文字或数字的最小长度，以及摘录是否逐字出现。「无关」需要各摘一个段内短语和题内短语。程序无法核验填写者身份，也无法判定理由在语义上是否成立。
3. 揭盲后可调阅完整原段和上下文，另记第二次判定、改判理由和日期。一题可以接受多个支持段落。无据题的首条若能说明实验边界，可记作边界材料。原始判读表继续保存，以便区分看到来源前后的判断。

```sh
node scripts/research/section-search-blind-review.mjs --check
node scripts/research/section-search-blind-review.mjs --reveal /path/to/已填判读表.md
```

空表、缺少任一判定、改动题面或填写未在该段出现的引文，都会在输出映射前报错。该流程依靠分开发送材料来维持盲态；仓库可见者可以自行查看公开的历史报告。`--print-form` 可在本地重建空白题面。映射 SHA-256 为 `947051b480c646aa063e374b823a0c6c0130724155c30301f3c89836e25c4cb6`。

## 独立留出题

[holdout.json](holdout.json) 在运行前冻结了 6 道简体题，AI 应用、LLM 与具身实验各包含一个有据题和一个缺乏指定测量的题。六题来自不同文章，在 v1/v2 报告的标注和前五候选中均未出现。评估使用原归档的 513 个段落，留出的范围是问题和证据来源。文件内的 `pointer`、`quote` 和 `support` 属于待审资料，留给主持人对照。

### 收集人工依据

判读者只需要[六道题目](holdout-questions.md)和[冻结语料](../../apps/web/tests/fixtures/section-search-corpus-v1.json)。请先独立找证据，再与主持人逐题核对。主持人可增补可接受的段落。若需换题或改题，另存一个版本并在运行前重新固定指纹。

从仓库根目录生成独立的复核模板。题目表的顺序与模板一致。

```sh
node scripts/research/section-search-blind-review.mjs --holdout-review-template > holdout-reviewed.json
```

填入实际复核日期 `reviewedAt`，格式为 `YYYY-MM-DD`。有据题填写 `evidence`，每项包含冻结语料的段落 `id` 和该段逐字引用 `quote`，并删除该题空白的 `missing` 字段。无据题保留 `evidence: []`，在 `missing` 中写下缺少的资料或测量条件。脚本校验覆盖范围、日期和引文，判读依据由复核者决定。

### 运行一次基线

判定和排序方案锁定后执行命令。输出保存在自选路径，旧版报告继续作为历史归档。

```sh
node scripts/research/section-search-blind-review.mjs --evaluate-holdout holdout-reviewed.json > holdout-results.json
```

报告记录题目、人工复核稿、语料与检索源码的指纹，以及前五命中数和无据题返回候选数，均附分母。逐题列出候选的原文与出处。第三项由人工读取有候选的无据题首条，记录其中能解释证据边界的条数，再除以这类题数。报告会标记第三项待复核，分母为零则记作不适用。这批每个方向只有两题，可用来定位具体现象。

### 开发集上的单文候选上限

固定词项和打分，在 v2 开发集完整排序后比较每篇文章最多保留 1、2、3、4 段及不设上限。上限为 1 时，前五命中 6/12；其余均为 8/12。五种方案均有 5/8 道无据题返回候选，现有每文最多两段的设置继续作为基线。
