### 首页从问题进入研究

首页首屏改为“先猜一个结果，再看证据”。四个问题可以先预测、直接揭晓、改变条件再比较，随后进入文章、原始证据、固定代码或学习路线：

| 问题 | 可变条件 | 数据与边界 |
| --- | --- | --- |
| 重试会不会执行两次 | 无键、相同键、服务重启 | 从幂等重试原文提取 2/1/2 次归档结果；过程图不发送 HTTP |
| 少算后是否更快 | 重新签名、固定签名 | 从开销文章提取完整重算 252.7、重新签名 682.7、固定签名 273.6 微秒中位数；限定小型 CPU 教学模型 |
| 经过目标是否等于停稳 | 1/2kg 与 Kd 0/18/36 | 原文六组 MuJoCo 结果；最大超调标记不是插值轨迹，不执行新仿真 |
| 真实引用能否支持答案 | 正确配置、旧版、开发环境、被改写的值 | 使用原文原创合成配置；只核对一个字段，不冒充模型输出或完整 Java 契约 |

结果和 40 位提交链接在构建时从原文章生成，未维护第二份手工结果集。数据缺失、无效数值、重复条件或不固定来源会阻止生成。揭晓前不绘制任意长度的计时条或任意超调位置。交互不调用模型、不追踪预测、不增加存储或依赖。

界面沿用品牌、夜间/护眼主题和现有导航。四个方向分别使用已有主题色；过程示意、计时条、最大超调与配置表服务于问题解释。旧的重复工坊宣传从首页移除，实践页中的原功能保留；近期文章、代表项目、外部资讯与阅读路线仍可直接访问。
