# 国际化与内容发现

## 路由与职责

zh-CN 是源语言，路径不带前缀；zh-TW 使用 `/zh-TW/`，英文使用 `/en/`。同一内容保持相同 slug。

主导航仅保留 Articles / AI Journey / Build / Radar / About。`/articles` 和 `/build` 是发现入口，内容仍由现有 Docs、Blog、Projects、Labs 数据源维护。Research、Papers、Notes、Now、Timeline、Changelog 继续保留，通过上下文与 Footer 发现。

## UI

Journey 虚拟实验室沿用 `/journey/virtual-lab` 的三语言路径；页面标题、引擎/环境等标签、实验目标、流程节点和状态均进入 code.json。MuJoCo、ROS2、ManiSkill、Isaac 等专名保留；普通名称如虚拟机器人、数据集、领域随机化随语言切换。服务端组件共用原消息字典，不新增翻译服务。

共享组件使用 `apps/web/runtime/Translate.jsx` 和 `i18n/<locale>/code.json`；新版导航和页脚使用站点语言上下文。新增固定文案使用可读的语义 ID；已有 UI 保留 `ui.<hash>` 稳定 ID，不在浏览器内做字符替换。

繁中技术术语参考 `i18n/terminology/zh-TW.json`。不对中文文章执行运行时繁简转换。产品名称、技术专有名词和论文原始标题可保留英文；栏目、状态、分类、时间单位等普通界面文案必须跟随所选语言。共享标签通过 `src/utils/ui-labels.js` 调用站点 runtime 的 translate，翻译仍由 code.json 管理，不改写内容数据或浏览器 DOM。

## 正文与版本

中文文章仍在 `docs/`、`blog/`。对应译文使用 按语言和内容类型组织的目录，例如：

- `i18n/en/docs/ai-apps/java-first-llm.md`
- `i18n/zh-TW/docs/ai-apps/java-first-llm.md`

`data/localization.json` 记录源文件和译文文件的元信息；它不是第二份正文或文章列表。

状态：`ORIGINAL`、`AI_TRANSLATED`、`REVIEWED`、`OUTDATED`、`MISSING`。只有用户真实审核译文后才能设置 `REVIEWED`。

每项记录维护 `sourceLocale`、`sourceUpdatedAt`、`sourceRevision`；每个译文维护 `translatedAt`、`sourceRevision`、`translationRevision`、`status`。revision 是统一 LF 换行后的文件 SHA-256。

更新流程：

1. 编辑中文正文并更新内容日期。
2. 运行 `npm run i18n:check`。这只是提示，不阻断中文构建。
3. 若需同步译文，编辑对应文件并核对示例、数据、链接。
4. 使用 `scripts/i18n/check.cjs` 的 `revision(file)` 计算指纹，更新 manifest；未人工审核时使用 `AI_TRANSLATED`。
5. 运行测试与三语言构建，确认语言提示及原文入口。

构建时计算实际源指纹；发现源或译文版本变化会标记待同步。缺失文件有提示，不因翻译检查阻断中文发布。Markdown 内容处理错误仍会按正常构建规则报错。

## 缺失译文

Docs 显示语言提示和中文原文入口，不静默展示中文长文。Blog 使用通用内容 wrapper 检查当前语言状态，缺失时只展示原文入口；已有文章另有本地化标题入口。未来新增中文 Blog 不强制翻译正文，也不会静默展示整篇中文回退。Projects / Labs 先提供本地化标题、简介、状态和仓库链接，缺失长文时跳转中文原文。

第一篇 Java 模型调用文章已提供 en / zh-TW 示例，均为 `AI_TRANSLATED`，没有宣称人工译文审核。

## 内容索引与搜索

`lib/content/content-index.cjs` 从文档、随笔数组和项目数据聚合。`writingEntries` 只收录 published 的 doc/note/paper/blog，排除 MISSING、规划和 Radar。

每个 locale 单独生成 `search-index/default/index.json`。当前语言缺失的原创文章不进入搜索。搜索分 WRITING、BUILD、DISCOVER，Learning 路线可检索。Radar 保留原始及已有翻译标题关键词，以支持跨语言发现，但不把所有语言摘要打进搜索结果。

Paper abstract guide 是 `to-read`，不会伪装成已经完成的 Paper Note。未来正式 Paper Note 使用现有正式内容 metadata 接入 Articles。

## Radar

页面只读构建期结果。`projectSignal` 只投影当前语言摘要，保留 originalTitle、来源、日期与内容归属。无当前语言译文则展示 SOURCE LANGUAGE；已有翻译显示 AI TRANSLATED。自动翻译采集仍暂停，此次不调用模型、不增加定时翻译任务。

## SEO 与验收

canonical、hreflang（含 x-default）与多语言 sitemap 由 Next.js App Router 生成，不额外叠加 Head 标签。旧中文地址与旧 redirect 保留。

验证命令：`npm run i18n:check`、`node --test tests/*.test.mjs tests/*.test.cjs`、`npm run build`。项目目前没有独立 lint/typecheck script，不虚报执行结果。

Next.js 在 `/sitemap.xml` 中汇集三语言路由，`app/robots.js` 声明这一入口。

Journey 的服务端页面直接读取同一 code.json 的 journey.* 文案；/learning 保留为旧学习路线入口。

Journey 栏目名称统一使用 journey.nav / journey.title：简体为「AI 学习之旅」，繁体为「AI 學習之旅」，英文为「AI Journey」。导航、页面标识、搜索结果和页面 metadata 共用这些翻译键；/journey slug 保持不变。
