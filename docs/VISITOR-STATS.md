# 访客统计（Vercel only）

首页展示累计浏览与匿名访客、近 7 天热门文章、模块与国家/地区；文章页显示近 7 天浏览。无有效数据时不显示假数字。没有独立数据库，也没有“我来过”计数。

## 启用

1. 在 hohoo-blog 项目的 Analytics 页面启用 Web Analytics。官方 SDK 仅在 Production 部署加载，预览和本地不计数。
2. 为 Production 添加服务端变量 `VERCEL_ANALYTICS_TOKEN`（具有目标项目读取权限的 Vercel access token）、`VERCEL_ANALYTICS_PROJECT_ID` 和团队项目所需的 `VERCEL_ANALYTICS_TEAM_ID`。不要使用 NEXT_PUBLIC 前缀，不要将 token 提交到 Git。
3. 重新部署，在控制台确认真实访问事件，再检查 `/api/visitors` 和首页。没有权限或套餐不允许 API 时保留未启用/不可用状态，不升级付费套餐。

公开展示与采集独立：没有读取 token 仍可在 Vercel 控制台查看已启用的采集数据。统计无法补回接入前的历史访问。

## 口径与边界

- 累计量来自 count 接口，榜单来自最近 7 天 aggregate；文章浏览量也是近 7 天，不是假装全历史总量。
- 语言路径合并 pageviews，匿名访客只使用上游总量，不累加页面访客数。Vercel 匿名识别不等于真实独立人数。
- 热门文章只包含已发布 doc/blog；外部单条 Radar 不混入原创榜单。模块表示所属页面浏览总和，不代表按钮点击次数。
- 路径结果最多 1000 个，Others 不分配到任何文章；榜单是已返回且匹配公开内容的统计。缺失路径不显示为 0。
- 只公开至少 3 位匿名访客的国家/地区，不公开城市、IP 或个体轨迹。上游地理识别及匿名化由 Vercel 管理，见官方隐私说明。
- SDK 去掉访问 URL 的查询参数与锚点，不增加搜索、笔记或学习状态事件。仅生产环境采集。
- 浏览器离屏不请求统计，各组件共享 10 分钟请求；服务端与 CDN 缓存 10 分钟。请求超时/失败不影响正文。密钥只在服务端使用，公开接口不接受任意查询参数。
- 当前功能需要在真实 Vercel 账户中验证权限、配额和事件流；本地未配置状态不代表已启用线上统计。

参考：https://vercel.com/docs/analytics/web-analytics-api 与 https://vercel.com/docs/analytics/privacy-policy 。

## 本轮验证

- 42 项测试通过，包含 URL 脱敏、语言归并、非法数字拒绝、路径白名单及地域小样本隐藏。
- 生产构建通过；141 个现有页面路由检查通过，核心页面继续静态生成。
- 本地 `/api/visitors` 返回 unconfigured；首页未配置状态在 1440/1280/1024/768/430/375 屏宽无横向溢出，验证了深浅主题、三语言文案与键盘展开说明。
- Java 文章页显示统计暂不可用，浏览器没有 error/warn。
- 尚未验证真实数据榜单布局与生产采集全链路：当前没有读取凭据，Vercel 管理页访问超时。没有将测试数据注入公开界面。
- 全仓格式检查仍有 18 个原有文件告警，本次修改文件已格式化；未进行无关批量修改。
