- [ ] 人：复现既有 Demo，确认 Java 环境、当前可用模型与调用预算；提供脱敏日志。
- [ ] AI：在独立 Demo 中实现全历史、最近完整一轮、无历史三种策略，明确保留当前问题。
- [ ] 人 + AI：先写断言：消息顺序正确、输出成功后才追加助手、失败不残留未完成回合、重启不保留内存历史。
- [ ] AI：用离线 fixture 测试协议/状态行为；明确它不能证明真实模型效果。
- [ ] 人：批准后执行真实对话，包括普通输入、包含引号、已知事实追问与读取失败。
- [ ] 人 + AI：逐条核验输出，保留请求/响应、模型标识、参数、时间、代码提交与错误，不保留密钥。

- [ ] 人 + AI：共同写 6 个小型虚构事实题，每题答案明确；材料标记为人工实验数据，不能当作用户真实信息。
- [ ] AI：构造固定材料的三种位置版本，以及删除事实的无证据对照；保持问题、模型、采样和输出格式一致。
- [ ] 人：审定评分规则（正确 / 错误 / 明确不知道）、每种条件的重复次数与预算，执行前冻结版本。
- [ ] AI：提供可运行脚本、逐题 JSONL 记录模板与配对结果表；先 dry-run 展示预计请求数，未经批准不调用 API。
- [ ] 人 + AI：检查事实是否被助手回答或题目泄漏，避免“删除了用户消息但助手仍重复答案”的混杂因素。
- [ ] 人：执行真实调用并人工复核；失败/超时单列，不混入语义正确率。
- [ ] 共创交付：一篇真实 Lab、一份可复现数据与“上下文并非长期记忆”的短 Note 草稿。
