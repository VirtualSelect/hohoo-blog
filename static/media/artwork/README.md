# 三维表面材质

三张本地材质图由本次任务的内置图像生成工具生成，用于真实WebGL几何的颜色、细小表面凹凸与粗糙度；不是设计稿截图、背景海报或实验资料。没有外部网络来源。

- obsidian-albedo.webp：黑曜石微细矿纹。
- paper-albedo.webp：棉纸纤维。
- linen-albedo.webp：原色亚麻织纹。

均为均匀漫射、无物体/文字/投影的可平铺基色图。通过正常UV与三维灯光显示，失败时保留程序材质。生成PNG原稿保存在本次会话可视化目录的artwork-materials中；网页只提供等分辨率WebP，合计861,378 bytes，无额外图像库依赖。
